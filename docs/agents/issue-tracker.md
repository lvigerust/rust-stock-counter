# Issue tracker: Obsidian

Issues and specs for this repo live in the Obsidian vault's `Stock Counter` project, also reachable through the `TODO.md` link at the repo root. The `todos` skill defines the item format and how to create and close items; this file maps the engineering skills' issue-tracker operations onto it.

## When a skill says "publish to the issue tracker"

Create a todo. For a spec with implementation tickets, write the spec as a reference and add one TODO item per ticket that links back to it.

## When a skill says "fetch the relevant ticket"

Find the item in `Tasks/TODO.md` and read its linked spec in `References/`, if it has one.

## Comments

Append to the spec under a `## Comments` heading. Create the spec if the item doesn't have one yet.
